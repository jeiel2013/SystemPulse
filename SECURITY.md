# Security policy

[English](SECURITY.md) | [Português Brasileiro](SECURITY.pt-BR.md)

SystemPulse is a development preview. Security fixes are made on the current
development branch; there is no stable release yet.

Please report a suspected vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/jeiel2013/SystemPulse/security/advisories/new)
if it is available for this repository. If that channel is unavailable, open
an issue asking maintainers for a private contact method **without** including
exploit steps, private data, or credentials. Include affected versions,
reproduction steps, and impact in the private report. We will acknowledge and
triage reports as maintainer capacity allows; no response-time guarantee is
made during the preview.

SystemPulse is read-only by default and sends no telemetry. Enabled third-party
collector plugins run with the current user's permissions; install and enable
only trusted plugins. Reports may contain host and process information; review
them before sharing. Never include secrets in public bug reports.
